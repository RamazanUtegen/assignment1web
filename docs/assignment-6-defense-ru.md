## Что спросить могут

- **Что такое `$`?** Короткое имя функции jQuery. Она возвращает коллекцию с методами библиотеки. Для DOM-элемента можно использовать `$(element)`.
- **`.attr()` и `.prop()`?** attr читает/меняет атрибут HTML, например src или aria-expanded. prop работает со свойством DOM, например disabled, hidden или inert.
- **Зачем внешний файл?** Разделяет структуру, оформление и поведение; один файл подключается на всех страницах.
- **Почему input, а не только keyup?** input срабатывает и при вставке мышью, очистке поля и вводе с экранной клавиатуры.
- **Почему не `.html(query)`?** Это могло бы интерпретировать пользовательский текст как разметку. `.text()` и текстовые узлы сохраняют ввод как текст.
- **Работает ли сайт без CDN?** Да, есть локальный jQuery. Это проверяется отдельным тестом с заблокированным запросом к CDN.
- **Зачем callback complete?** Валидация и отображение результата принадлежат прежнему модулю, а jQuery управляет ожиданием. Callback завершает исходную операцию после задержки.
- **Как проверяли?** Chromium и Microsoft Edge, десктоп и телефон; все шесть страниц, реальное содержимое буфера, отказ clipboard, спецсимволы в запросе, двойная отправка, ленивая загрузка и отсутствие JS-ошибок. Результаты записаны в JSON.

## Трудности и решения

Прежний поиск мог конфликтовать с новым: оставлен один jQuery обработчик отображения, а сохранение города сообщает об изменении через событие. Скрытые слайды не видны при обычной проверке viewport: их изображения загружаются по событию slide.bs.carousel. При быстрой смене уведомлений старый таймер мог скрыть новое сообщение: таймер и очередь анимации очищаются. Некорректный запрос вроде `[` мог сломать regex: ввод экранируется.
