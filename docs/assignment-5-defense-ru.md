# Подготовка к защите Assignment 5

Откройте `index.html` и `js/experience.js` рядом. Сайт работает без сборки и интернета.

1. **DOM.** В `renderDestinations` и `renderRating` объясните `querySelectorAll`, `textContent`, `classList`, `hidden`. Покажите рейтинг 4/5.
2. **События.** Найдите `addEventListener` для `click`, `input`, `keydown`. Покажите поиск, фильтр и перемещение фокуса стрелками.
3. **switch.** `matchesCategory` выбирает условие фильтра. `default` показывает все направления. Второй `switch` обрабатывает клавиши меню.
4. **Callback.** `changeStep(1, showStep)` передаёт функцию, затем вызывает `onStepChanged(step)`. Покажите Next → имя → Back → Next: поля не удаляются, поэтому имя сохранено.
5. **Объект и метод.** Объект направления хранит название, категорию, описание и массив остановок. `getRoute(days)` использует `this.stops.slice(0, days)`.
6. **Массивы и циклы.** `filter` отбирает, `map` преобразует, `forEach` обновляет элементы. Цикл `for` создаёт `li` через `createElement`.
7. **Звук.** Нота включает Web Audio. Следующий сигнал останавливает предыдущий; `gain` плавно уменьшает громкость; `onended` освобождает узлы.
8. **Анимации.** Нажмите фильтр, сердце, Next. JS меняет классы, CSS задаёт движение. `prefers-reduced-motion` отключает эффекты.
9. **Файлы.** HTML — структура, `editorial.css` — дизайн, `experience.js` — поведение. В HTML нет встроенных обработчиков.
10. **Прежние функции.** Покажите FAQ, окно About Us, проверку формы, часы и Change background внизу, стрелки и миниатюры галереи.

`localStorage` хранит только тему, ID избранных направлений и оценки. Имя остаётся в памяти страницы и выводится через `textContent`.

Сайт — учебный путеводитель: формы не отправляют сообщения и не бронируют поездки. Для требования callback выбран вариант с многошаговой формой.
